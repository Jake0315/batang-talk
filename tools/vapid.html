푸시 알림 키(VAPID) 만들기

버튼을 누르면 이 브라우저 안에서 키 한 쌍을 만들어요. 어디로도 전송되지 않아요. 한 번만 만들어서 계속 써야 해요(바꾸면 모두 알림을 다시 켜야 해요).

공개 키 → app/config.js의 VAPID_PUBLIC_KEY, 그리고 Edge Function 비밀 값 VAPID_PUBLIC_KEY

비밀 키 → Edge Function 비밀 값 VAPID_PRIVATE_KEY 에만

비밀 키는 GitHub, config.js, 채팅 어디에도 올리지 마세요. Supabase의 Edge Function 비밀 값에만 넣어요.
